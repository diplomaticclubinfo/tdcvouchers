Import vouchers from CSV

Dates: DD-MM-YYYY (day first; YYYY-MM-DD also works). Up to 1,000 rows per import. In Excel, format phone number columns as Text so leading zeros and + signs are kept. Updating only needs a "Voucher number" column plus the columns you want to change; a file exported with Download QR links (CSV) works too.

Export vouchers with QR links

One CSV with every voucher's QR link, category, dates, status, title, recipient, contact and remarks. Leave a filter empty to include everything. The file can be edited in Excel and imported back using "Update existing vouchers".

Categories

These appear in the voucher category lists, filters and reports. Renaming a category updates every voucher that uses it. A category can only be deleted when no voucher uses it.

Backup and restore

Backup

Downloads one file with everything: numbering settings, users, vouchers (including redeemed, voided and deleted ones) and the audit log. Keep the file somewhere safe: it contains users' PINs in scrambled form.

Restore

Choose a backup file. Restore adds anything that is missing and never overwrites or deletes existing records, so it is safe to run more than once. Use it to rebuild a new or emptied database.

Reset data

Resetting permanently deletes data. It can only be undone by restoring a backup file. Tick only what you really want to clear.
